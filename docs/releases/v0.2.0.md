# v0.2.0

## Positioning

`v0.2.0` is the first explicitly versioned research release of `adzuki-snp-pipeline`. It is an experimental/research Nextflow pipeline, not a production SLA, a guarantee of variant-call accuracy, or validation for every adzuki dataset.

## Validated scope

The repository's synthetic test profile and CI exercise the paired-end WGS samplesheet and configurable reference contracts, Nextflow DSL2 workflow, raw and trimmed FastQC, fastp, BWA-MEM2 mapping, read-group-aware sample merge, GATK MarkDuplicates, SAMtools BAM QC, HaplotypeCaller gVCF generation, GenomicsDBImport, GenotypeGVCFs, raw cohort VCF generation, SNP/indel selection, configurable hard filtering, variant QC, GS normalization/classification/panel generation, and MultiQC integration. Pipeline and module contracts are covered by Python unit tests, Nextflow lint, nf-test, and GitHub Actions. Runtime tool containers are pinned by immutable digests.

This automated synthetic evidence does not by itself establish biological accuracy or real-cohort scalability. The real-cohort evidence below covers the older pipeline lineage through GS panel generation; MultiQC's distinct evidence boundary is stated under Reproducibility and QC.

## Real-cohort evidence

Only public WGS data from BioProject `PRJNA1138464` was used for committed real-cohort evidence.

- A 5-sample FASTQ-to-GS-panel E2E run completed and produced a populated panel with 4,298,980 variant rows x 5 samples. See [`docs/real_cohort_e2e.md`](../real_cohort_e2e.md).
- Staged 10- and 20-sample E2E validation completed. The 20-sample panel contained 9,252,873 variant rows x 20 samples, with matching variant and sample metadata dimensions. See [`docs/real_cohort_scale_validation.md`](../real_cohort_scale_validation.md).
- The 30-sample stage was deliberately skipped after review of cost, information gain, and repeated scale-specific downstream resource findings. This is not evidence that 30 samples would fail.
- The 327-sample full cohort was not run or validated.

The historical manifests preserve the pipeline version and exact commits used for those runs; they are evidence for those historical executions, not claims that the release-preparation commit itself was used retrospectively.

## Reproducibility and QC

`CLASSIFY_NORMALIZED_VARIANTS` no longer materializes all eligible records in memory. Formal targeted replay of the existing public 10- and 20-sample normalized VCF artifacts confirmed scientific output equivalence. Classifier Python peak RSS was 20.83 MiB and 20.90 MiB respectively, with host swap delta 0 kB at both scales. Cgroup page cache is not treated as Python RSS. These were targeted classifier replays, not new FASTQ-to-panel E2E runs. See [`docs/classify_normalized_variants_streaming_benchmark.md`](../classify_normalized_variants_streaming_benchmark.md).

MultiQC 1.35 integration is verified with synthetic fixtures and standard MultiQC modules. Its explicit input allowlist contains raw/trimmed FastQC ZIPs, fastp JSON, MarkDuplicates metrics, and SAMtools flagstat/stats/idxstats. No real 20-sample MultiQC rerun was performed. See [`docs/multiqc.md`](../multiqc.md).

## Scientific boundaries

- The biological optimality of the configurable hard-filter thresholds has not been established for Longxiaodou 4, PRJNA1138464, or the adzuki population.
- `FILTER=PASS` means only that a record passed the configured rules. Without a truth set, this release makes no accuracy, precision, or recall claim.
- BQSR is deliberately excluded because validated known-sites for the selected reference have not been established.
- MAF filtering, call-rate filtering, LD pruning, imputation, GS model training, and GWAS are outside this release's pipeline contract.

## Known scale limits

- Real E2E execution is measured through 20 samples.
- The 30-sample stage was skipped with documented rationale and remains unmeasured.
- GenomicsDB batching above 50 samples is unvalidated. The default `genomicsdb_batch_size=50` is an initial operational value, not an optimization validated for 327 samples.
- The 327-sample full cohort remains unvalidated. No result in this release establishes a production SLA or general resource formula for 30 or 327 samples.

## Data handling

Committed validation evidence uses public genomic data only. Raw FASTQ, BAM, gVCF, large VCF, GenomicsDB workspaces, and other large run artifacts are not committed. Customer/private genomic data, credentials, private infrastructure identifiers, absolute home paths, and usernames are not included in release artifacts.

## Upgrade / compatibility notes

The pipeline manifest version changes from `0.2.0-dev` to `0.2.0`. This release preparation does not change workflow algorithms, scientific thresholds, resource allocations, parameters, schemas, or pinned tool/container versions. GS panel schema and dosage semantics remain documented in [`docs/gs_panel_data_contract.md`](../gs_panel_data_contract.md), and Joint Genotyping limits remain documented in [`docs/joint_genotyping_scaling.md`](../joint_genotyping_scaling.md).
